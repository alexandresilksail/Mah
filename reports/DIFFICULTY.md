# MahLeMah v2.0.0 难度模拟报告（发布压力测试）

> 本报告由 `npm run test:release`（tools/stress_release.mjs）在真实运行后自动生成。

## 1. 实际模拟数量

- 发布测试样本：每关 **1000 个 seed**（连续确定性序列，baseSeed 每关独立），全部 L1 / L2 关；
- 每个 seed 用 **6 种策略**各模拟 1 局，每关 6000 局，总模拟 **12000 局**；
- 每局生成后都跑 证书序列 + 几何可解性 verify 双重校验；总耗时 203.4s；
- 日常快速测试另有 40 个固定 seed（npm test 的 [7] 段），与本发布测试完全分开。

## 3. 口径说明（必读）

- **随机机器人 100% 失败 ≠ 游戏难度成功**。random 必败只说明「不乱点不行」，是难度门槛之一而非充分条件；
- 完整信息贪心（greedy）的高通关率只证明「关卡可解」，不代表真实玩家的难度体验；
- 「带 10% 失误」（noisy）与 greedy 的差值衡量「失误惩罚」；失败进度中位数衡量「死局是否后置」；
- 平均槽位占用与开局可点花色数是结构指标（7 格槽位 + 波次剥离顺序有数学上限）；
- 本报告如实呈现所有数据，不筛选、不修饰；未达标项在 npm test 的软指标中以 ✗ 标注。
